# 使用指南

## 选择音频与标注对象

打开[标注工作区](https://rater.zaoan.today/annotate)，选择内置录音，或添加浏览器支持格式的本地音频。四个内置示例均为 60 秒，附[来源与授权](../public/audio/README.md)。

确定标注的是**音频表达的情绪**，还是**聆听时自身的感受**。开始标注后，该对象固定；需要更换时请建立新会话。

| 限制 | 默认值 |
| --- | --- |
| 本地音频 | 每个文件最长 30 分钟、最大 100 MiB |
| 本地集合 | 当前标签页最多 20 个不同文件 |
| 配置音频库 | 最多 50 个片段 |
| JSON 导入 | 最大 100 MiB |

## 记录评分

点击「开始标注」，边听边在情绪坐标图中点击。横轴愉悦度从左侧的消极、不愉悦，向右侧的积极、愉悦增加；纵轴唤醒度从下方的低唤醒向上方的高唤醒增加。两个坐标轴均为 **0–1**，唤醒度不等于音量。

附近的词语用于帮助定位，不代表系统自动识别出的情绪。也可以使用触屏、方向键或独立滑块，并随时切换中英界面。

仅试听不会修改数据。每轮首次输入前为空缺；输入后保持最近评分，直到下一次输入或该轮结束。时间线空白表示缺少评分，不表示中性情绪。

## 回顾与修改

暂停后可以定位回听。「从此处重新标注」会开始新一轮，覆盖本轮对应的时间区间，包括首次输入前的空缺。区间之外保留原有评分。「撤销」会撤销最近一轮标注，并保留其原始历史。

暂停、跳转、缓冲、隐藏页面或音频结束时都会停止标注；继续时需再次手动开始。精确边界与中断规则见[标注协议](PROTOCOL.md)。

## 保存与继续

草稿保存在当前浏览器的 IndexedDB，不同音频分别保存。草稿不会跨设备、跨浏览器同步；清除网站数据会删除草稿。保存失败时，界面会明确提示。

草稿不包含本地音频文件。刷新后请重新选择原文件，工具会校验 SHA-256 指纹后恢复关联。切换音频不会覆盖其他音频的草稿。

## 导出与导入

| 格式 | 用途 |
| --- | --- |
| **JSON** | 备份原始评分、修改历史、备注、音频身份和界面配置；可导入以恢复标注 |
| **CSV** | 分析 10 Hz 派生时间序列；空缺保持为空，保持值引用原始输入的时间 |

导入自由标注 JSON 会创建新的本地会话并保留来源，不覆盖已有记录。旧版 JSON 的未知信息保持未知。清除浏览器数据或更换网站地址前，请先导出重要标注。

## 数据范围

默认应用不会向研究 API 上传本地音频或标注。访问托管网站仍会产生加载页面和内置录音的正常请求。可选的研究提交后台默认关闭，需单独完成[部署与所有者配置](DEPLOYMENT.md)。

本工具采集人的主观评分。内置录音没有标准情绪答案，软件不进行诊断评分或自动情绪识别。用于研究前，请阅读[标注协议及其限制](PROTOCOL.md#7-relationship-to-the-paper--与论文的关系)。
